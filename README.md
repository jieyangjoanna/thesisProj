## Dataset
 The dataset (4GB) is archieved on Zenodo:
 ./part1_hw/data/: DOI: 10.5281/zenodo.17495177 (https://doi.org/10.5281/zenodo.17495177)
 ./part2_sw/data/: DOI: 10.5281/zenodo.17496532 (https://doi.org/10.5281/zenodo.17496532)

 ## Setup Instructions
 1. clone this repo
 2. Download and extract the data archieves from Zenodo:
 ```bash
    wget https://zenodo.org/records/17495177/files/part1_hw_data.tar.gz
    wget https://zenodo.org/records/17496532/files/part2_sw_data.tar.gz
    cd part1_hw
    tar -xzf part1_hw_data.tar.gz
    cd ../part2_sw
    tar -xzf part2_sw_data.tar.gz
 ```
 3. Run the code from each sub-directory
